# SmartBoard

**A Smart Management Solution for Modern Property Management**

## About the Project

SmartBoard is a property management solution designed to simplify communication and management between landlords and tenants through a centralised digital platform.

The project aims to address common property management challenges by providing a more organised and accessible way to manage property-related activities.

## Key Features

The proposed system aims to include:

- **Property Management:** Manage property-related information.
- **Tenant Management:** Organise tenant information and interactions.
- **Maintenance Management:** Report and track maintenance requests.
- **Communication:** Improve communication between landlords and tenants.
- **Notifications:** Keep users informed about relevant updates.

*Note: Features are subject to refinement during the requirements engineering and design phases.*

## Technology Stack

| Component | Technology |
|---|---|
| Mobile Application | React Native |
| Frontend Language | TypeScript |
| Backend | Java, Spring Boot |
| Database | PostgreSQL |
| Machine Learning Service | Python, FastAPI |

## System Architecture

SmartBoard follows a modular architecture consisting of a cross-platform mobile application, a Java-based backend, a PostgreSQL database and a dedicated Python-based machine learning service.
